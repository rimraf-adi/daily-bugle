# `llm_router` Module Specification

Unified LLM inference and model routing engine powered by **OpenRouter**, designed for autonomous agents, newsletter summarization pipelines, and multi-model orchestration.

---

## 1. How Agents Are Supposed to Identify It

Autonomous agents, LLM planners, and subagent executors should identify this module via the following capability contract:

### Capability Signature
- **Namespace:** `llm_router` (inside `backend`)
- **Primary Role:** Frontier and open-source model routing via OpenRouter API.
- **Default Model:** `openrouter/free` (auto-routes to available high-performance free models, e.g. Llama 3.3 70B, Gemini 2.0 Flash, etc.).
- **Supported Models:** Any model supported by OpenRouter (e.g. `anthropic/claude-3.5-sonnet`, `meta-llama/llama-3.3-70b-instruct`, `google/gemini-2.0-flash-exp:free`, `deepseek/deepseek-chat`).
- **Configuration:** Auto-resolves `OPENROUTER_API_KEY` from `backend/.env` or system environment.

### Agent Intent Routing Matrix

| User Goal / Agent Intent | Recommended Call | Return Type | Description |
| :--- | :--- | :--- | :--- |
| **"Ask a question / chat with LLM"** | `router.complete("Hello!")` | `ChatResponse` | Single prompt execution with optional system instructions. |
| **"Run multi-turn conversation"** | `router.chat(messages)` | `ChatResponse` | Sends list of `ChatMessage` or `dict` items (`role`, `content`). |
| **"Draft newsletter from arXiv digest"** | `router.generate_newsletter(digest)` | `ChatResponse` | Accepts `NewsletterDigest` and produces complete newsletter copy. |
| **"Quick one-off generation"** | `generate_completion(prompt, model=...)` | `ChatResponse` | Stateless top-level helper without client setup. |
| **"Check which model was routed"** | `response.model` | `str` | Inspects exact model chosen by OpenRouter (e.g. `llama-3.3-70b:free`). |

## 3. Configuration & Environment Variables

Place your key in `backend/.env`:

```bash
OPENROUTER_API_KEY=your_openrouter_api_key_here
```

The module automatically resolves and loads `.env` upon initialization.

## 4. Usage Examples

### Example 1: Basic Chat Request (Matching OpenRouter Quickstart)
```python
from llm_router import LLMRouter

router = LLMRouter()

response = router.chat([
    {"role": "user", "content": "Hello! What can you help me with today?"}
])

print(response.content)
print("Model used:", response.model)
```

### Example 2: Quick One-Off Completion
```python
from llm_router import generate_completion

response = generate_completion("Explain quantum entanglement in two sentences.")
print(response.content)
```

### Example 3: End-to-End Newsletter Pipeline (`arxiv` + `llm_router`)
```python
from arxiv import fetch_newsletter_digest
from llm_router import LLMRouter

# 1. Ingest latest research papers
digest = fetch_newsletter_digest(
    categories=["cs.AI", "cs.LG"],
    max_results=3,
    topic="Daily AI Innovations"
)

# 2. Route prompt to OpenRouter to write the newsletter draft
router = LLMRouter()
newsletter = router.generate_newsletter(digest)

print(f"Generated via: {newsletter.model}")
print(newsletter.content)
```

## 5. Output Model: `ChatResponse`
- `content`: Text response generated by the model.
- `model`: Exact model ID selected by OpenRouter.
- `usage`: Dictionary with `prompt_tokens`, `completion_tokens`, and `total_tokens`.
- `id`: OpenRouter generation ID.
- `to_dict()`: Clean dictionary representation.
